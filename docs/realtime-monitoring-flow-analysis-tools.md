# پایش لحظه‌ای حمل‌ونقل کالا و تحلیل جریان‌ها — فهرست ابزارهای منبع‌باز قابل ادغام

> هدف این سند: پاسخ به دو پرسش «چه چیزهایی را همین حالا داریم؟» و «چه چیزهایی از اکوسیستم منبع‌باز
> می‌توانیم اضافه کنیم؟» برای دو حوزهٔ (۱) پایش مستمر و برلحظهٔ فرایند حمل کالا و (۲) تحلیل جریان‌های
> حمل‌ونقل بین نقاط. هر گزینه با مخزن/وب‌سایت، مجوز، جای دقیق ادغام در اطلس و سطح تلاش پیاده‌سازی آمده است.

---

## بخش ۱ — آنچه هم‌اکنون در اطلس پیاده شده (مبنای ارزیابی شکاف)

| حوزه | قابلیت فعلی | محل کد |
| --- | --- | --- |
| صف زندهٔ گمرک | `GET /api/border-park/status` — پروکسی نوبت‌دهی رسمی (کل صف، انتظار، اطمینان) + لایهٔ حباب و گیج | `server.ts`، `MapAtlas` |
| جریان مرزی | `GET /api/border-flow` — ترکیب منابع رسمی (گمرک/راهداری/Comtrade) و اخبار با اعتبارسنجی چندمنبعی | `server.ts`، `BorderFlowDashboard` |
| ناهنجاری جریان | `GET /api/border-flow/anomalies` — جهش/سقوط/تعارض/غیرواقعی با شدت و شواهد | `borderFlow.ts`، لایهٔ G8 |
| ماتریس ریسک ترکیبی | نمرهٔ ۰-۱۰۰ از صف + آنومالی + اطمینان داده + تردد (G8) | `MapAtlas.multiLayerRiskScore` |
| هوا بر مسیر | `GET /api/weather` (Open-Meteo بدون کلید، کش ۲۰ دقیقه) | popup کریدور |
| مسیریابی/ایزوکرون | OSRM (fallback) + ORS HGV برای کامیون سنگین | `server.ts`، `RouteStudio` |
| جریان متحرک/کاروان/تور | انیمیشن dash جریان (B1)، کاروان B8، تور پروازی H4، روایت H5، کره H2 | `MapAtlas` |
| کوروپلت استان‌ها | `GET /api/provinces` (geoBoundaries ADM1، کش ۲۴ ساعت) + هش حرارت | `MapAtlas` |

**شکاف‌های کلیدی:** ردیابی لحظه‌ای ناوگان/محموله (telematics)، جریان‌نگاشت OD واقعی بین نقاط،
پیش‌بینی سری‌زمانی و اعلان هوشمند، دادهٔ دریایی/بندری، و زیرساخت استریم بلادرنگ (وب‌سوکت/میان‌افزار).

## بخش ۷ — اولویت‌بندی پیشنهادی (کم‌هزینه‌ترین اثرِ بیشترین)

1. **H3 + HexagonLayer** (کم) — کانون‌های فشار روی نقشه از همان دادهٔ موجود.
2. **flowmap.gl** (متوسط) — لایهٔ قوس‌های OD بین گیت‌ها؛ جذاب‌ترین ارتقای تحلیلی نقشه.
3. **Traccar + Mosquitto** (متوسط) — نخستین لایهٔ واقعیِ ردیابی ناوگان؛ اتصال به anomalies.
4. **ADTK** (متوسط) — ارتقای موتور آنومالی فعلی در `api/*.py` بدون تغییر فرانت.
5. **ntfy اعلان‌ها** (کم) — بستن حلقهٔ پایش برای اپراتور.
6. **Fleetbase** (زیاد) — فقط وقتی محصول به سمت «سازمان حمل» برود.

> همهٔ موارد جدول‌ها با جستجوی وب مخازن رسمی GitHub در تاریخ ۲۰۲۶-۰۹ تنظیم شده‌اند؛
> پیش از هر ادغام، آخرین نسخه و CHANGELOG مخزن را بررسی کنید (لینک‌ها در ستون «مخزن»).
